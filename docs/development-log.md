## 2026-09-18 初始版本搭建

### 已完成功能
- 基础贪吃蛇：移动、吃食物、撞墙 / 撞自身结束、重新开始。
- 键盘控制：方向键 + WASD，禁止反向，按键缓冲避免一 tick 多次转向。
- 食物生成：收集空格列表随机生成，避免死循环；12% 概率生成奖励食物（+20）。
- BFS 自动寻路：队列 + visited + parent 回溯，障碍为蛇身（除尾巴）+ 边界。
- 贪心 / 生存 fallback：BFS 失败时按「可达空间 × 10 − 曼哈顿距离」评分选方向。
- AI 路径可视化：半透明蓝色圆点，可开关。
- 统计：手动 / AI 最高分、局数、当前分数、蛇长度、游戏时间，localStorage 持久化。
- Light / Dark 双主题，Canvas 同步变色。
- 高 DPI 适配：`devicePixelRatio` 缩放，resize 重 fit。
- 游戏循环：固定 tick 间隔 + requestAnimationFrame 渲染分离。
- 音效：Web Audio API，吃食物 / 奖励 / 结束 / 转向。

> **T5 说明**：测试用例 `snake=[{5,5},{4,5},{3,5}]`（头向右）时，`left` 方向指向 `(4,5)`，这是身体第二节而非尾巴。`ignoreTail=true` 只忽略最后一节 `(3,5)`，因此 `(4,5)` 正确地被视为障碍、`left` 不可走。这是**预期行为**，代码正确；测试用例的期望写错了。

**结论**：BFS 寻路、路径回溯、碰撞检测、食物生成、生存策略、AI 自动决策的核心逻辑全部正确，无逻辑 Bug。AI 在 25×25 棋盘上能稳定存活并持续吃食物，符合「不保证永生但生存能力强」的设计目标。

## 2026-09-18 第二轮扩展（可爱化 + 装扮系统）

### 新增功能

#### 可爱化小蛇角色（规格第二十三节）
- 蛇身从方块改为圆形 + 肚皮高光。
- 蛇头：圆头 + 眼白/瞳孔/高光 + 腮红 + 嘴巴。
- 朝向：眼睛 / 嘴巴 / 饰品随 `dir`（up/right/down/left）整体旋转（用 `fx,fy` 前向 + `px,py` 侧向向量计算）。
- 呼吸动画：`Math.sin(breathPhase) * 0.03` 缩放，不创建新对象。
- 吃食物脉冲：`eatPulse` 0→1 触发，每帧 -0.08 衰减，蛇头放大 0.18 倍。
- Game Over 闭眼 + 嘴角下弧（伤心表情）。
- AI 模式瞳孔更靠前 + 更窄（专注表情）。

#### 装扮系统 Snake Closet（规格第二十四、二十五节）
- 新增 `SKINS`（6 个皮肤）+ `ACCESSORIES`（6 个饰品）数据结构。
- 衣橱 Modal：预览 Canvas + 皮肤/饰品网格 + Apply/Default 按钮。
- 快捷键 `C` 打开，Esc / 点遮罩外关闭。
- 装扮仅影响视觉，**不影响 BFS / 碰撞 / 分数**。

#### 解锁系统（规格第二十六节）
- `checkUnlocks()` 在吃食物与游戏结束时调用。
- 解锁条件：score≥50→🍓草莓、score≥100→👑王冠、累计5局→🌸小花、AI累计20食物→🤖科技蛇。
- 新解锁弹顶部 Toast + 解锁音效，`localStorage` 持久化。

#### 食物丰富化（规格第二十六、二十七节）
- `FOOD_TYPES`：🍎🍓🥑🍞🍌🍒 6 种普通食物（均 +10），12% 概率生成 ★奖励食物（+20）。
- `drawFood()` 按类型用 Canvas 原生图形绘制（圆/弧/路径/贝塞尔），无外部图片。
- 加 `save()/restore()` 包裹，避免 `lineCap` 等状态污染后续绘制。

#### Current Snake 个性化（规格第二十九节）
- 右侧顶部新增卡片：头像 Canvas + 蛇名输入 + Skin/Accessory/Mode 展示。
- 蛇名默认「小绿」，最长 12 字符，存 `localStorage`。
- 头像随主题与装扮实时变化。

#### 粒子与细节反馈（规格第三十节）
- 吃食物生成 6~9 个爱心/星星粒子，~1s 自动清除，数组通常 ≤ 30。
- 用 `globalAlpha` 渐隐 + 重力下落，轻量。

### 解耦设计（规格第二十八节）
- `game.snake[]` 只存 `{x, y}` 坐标。
- `SKINS` / `ACCESSORIES` 只存视觉属性，仅 `render()` 读取。
- `findPathBFS` / `chooseSurvivalMove` / `updateAI` 只读坐标，与装扮完全无关。

### V8 沙箱验证（2026-09-18 第二轮）

复刻 `SKINS` / `ACCESSORIES` / `FOOD_TYPES` / `spawnFood` / `checkUnlocks` 到 V8 沙箱：

**结论**：装扮/食物/解锁的纯数据与逻辑层全部正确。BFS / 碰撞 / AI 控制器代码未改动，沿用第一轮 16 项测试结论。Canvas 渲染层（可爱蛇头/饰品/粒子）建议在浏览器中实测验收。
